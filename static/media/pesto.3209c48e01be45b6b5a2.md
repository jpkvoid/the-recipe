# Pesto

#pasta #dip #mortar #vegetarian #brunch #dinner #italian

## Ingredients
original / *cheaper substitute*
- Basil / *Rucola*
- Pine Nuts / *Walnuts*
- Pecorino
- Garlic
- Olive Oil
- Salt

## Preparation
1. In a mortar crush the garlic, turn into a paste using some salt to help grind
2. Toast the pine nuts and grind into a paste with the garlic
3. Grind the Basil
4. Add some olive oil little by little
5. Incorporate some grated pecorino 
6. Use as a spread, dip or as pasta sauce
7. If using for pasta, mix with some of the cooking water to make it creamy before adding the pasta
